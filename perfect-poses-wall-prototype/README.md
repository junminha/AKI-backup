# Perfect Poses

웹캠으로 전신 포즈를 인식해 다가오는 벽의 실루엣에 몸을 맞추는 로컬 브라우저 게임입니다. 카메라가 없는 환경에서도 데모 모드로 전체 게임 흐름을 확인할 수 있습니다.

## 실행

```powershell
npm install
npm run dev -- --host 127.0.0.1
```

브라우저에서 `http://127.0.0.1:5173`을 엽니다. 카메라 모드는 브라우저 권한 허용이 필요합니다.

## 게임 구성

- 난이도가 상승하는 포즈 벽 8개
- 마지막 0.52초의 포즈 적합도를 평균 내는 공정한 판정
- 점수, 콤보, 목숨, 로컬 최고 기록
- 카메라가 전신을 놓치면 벽 진행 자동 일시 정지
- 카메라 없이 확인할 수 있는 데모 플레이
- 데스크톱과 모바일 대응, 동작 줄이기 설정 지원

## 기술

- React, TypeScript, Vite
- MediaPipe Pose Landmarker 33개 관절 추적
- Canvas 2D 기반 관절형 벡터 아바타와 벽 렌더러
- Motion 오버레이 전환
- Vitest 점수 로직 테스트

모델과 WASM 파일은 로컬 `public` 폴더에서 불러오며, 카메라 프레임은 서버로 전송하거나 저장하지 않습니다. `avatar-studio` 프로젝트는 기술 검토와 로컬 MediaPipe 런타임 파일의 출처로만 사용했고 원본 파일은 수정하지 않았습니다.
