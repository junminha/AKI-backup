# Perfect Poses

웹캠으로 전신 포즈를 인식해 다가오는 벽의 실루엣에 몸을 맞추는 로컬 브라우저 게임입니다. 카메라가 없는 환경에서도 데모 모드로 전체 게임 흐름을 확인할 수 있습니다.

## 실행

```powershell
npm install
npm run dev -- --host 127.0.0.1
```

브라우저에서 `http://127.0.0.1:5173`을 엽니다. 카메라 모드는 브라우저 권한 허용이 필요합니다.

## 게임 구성

- 포즈 벽 8개, 통과 기준 65%, 벽이 다가오는 시간 3초 고정 (`src/game/poses.ts`의 `PASS_THRESHOLD`, `APPROACH_MS`)
- 마지막 0.52초의 포즈 적합도를 평균 내는 공정한 판정
- 화면 밖 관절은 판정 제외 — 아래 "보이는 관절만 판정" 참고
- 점수, 콤보, 목숨, 로컬 최고 기록
- 카메라가 몸을 놓치면 벽 진행 자동 일시 정지
- 카메라 없이 확인할 수 있는 데모 플레이
- 데스크톱과 모바일 대응, 동작 줄이기 설정 지원

## 보이는 관절만 판정

책상 위 웹캠은 보통 다리를 담지 못합니다. MediaPipe는 화면 밖 관절도 좌표를 추측해서 내놓기 때문에, 예전에는 그 추측값이 점수를 두 번 깎았습니다. 신뢰도 평균에 안 보이는 랜드마크 6개가 섞여 전체 점수에 곱해지는 값이 0.68로 고정됐고(= 최고 68점), 팔이 완벽해도 통과 기준을 넘길 수 없었습니다.

지금은 `src/game/tracking.ts`가 관절마다 따로 판단합니다.

- 관절을 이루는 두 랜드마크가 **화면 안에 있고** visibility가 0.5 이상일 때만 "보이는 관절"
- 몇 프레임 연속으로 만족해야 켜지고, 몇 프레임 연속으로 어긋나야 꺼짐 (경계에서 점수가 튀지 않도록)
- 점수는 보이는 관절만 평균, 신뢰도도 보이는 관절만으로 계산
- 안 보이는 관절은 벽과 같은 각도로 그려서, 화면에서 통과해 보이면 실제로도 통과

## 기술

- React, TypeScript, Vite
- MediaPipe Pose Landmarker 33개 관절 추적
- Canvas 2D 기반 관절형 벡터 아바타와 벽 렌더러
- Motion 오버레이 전환
- Vitest 점수 로직 테스트

모델과 WASM 파일은 로컬 `public` 폴더에서 불러오며, 카메라 프레임은 서버로 전송하거나 저장하지 않습니다. `avatar-studio` 프로젝트는 기술 검토와 로컬 MediaPipe 런타임 파일의 출처로만 사용했고 원본 파일은 수정하지 않았습니다.
