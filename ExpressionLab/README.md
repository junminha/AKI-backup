# 표정연구소 (Expression Lab)

웹캠 또는 업로드한 사진에서 얼굴 근육의 움직임을 브라우저가 **FACS Action Unit**으로 계측하고,
그 수치를 OpenRouter API가 전문적으로 판독해 주는 웹앱입니다.

포즈팝이 "몸 전체 포즈"를 다뤘다면, 이쪽은 "얼굴 표정"을 계측 장비처럼 다룹니다.

## 무엇을 판단하나요

브라우저에서 MediaPipe FaceLandmarker가 얼굴 랜드마크 478개와 블렌드셰이프 52개를 뽑아내고,
`src/face.js`가 이를 아래 전문 지표로 압축합니다.

| 지표 | 내용 |
| --- | --- |
| Action Unit 18종 | AU1(안쪽 눈썹 올림)부터 AU45(눈 감음)까지 FACS 코드별 강도 0~1 |
| 눈 종횡비 (EAR) | 좌우 눈이 얼마나 열려 있는지 |
| 입 종횡비 (MAR) | 입 벌림 정도, 얼굴 폭 대비 입 너비 |
| 입꼬리 기울기 | 한쪽만 올라간 비대칭 미소 탐지 |
| 눈썹–눈 간격 | 눈썹 올림·내림의 절대 근거 |
| 머리 각도 | 변환 행렬에서 뽑은 yaw / pitch / roll |
| 좌우 비대칭 지수 | 좌우 쌍 블렌드셰이프의 평균 차이 |
| Duchenne 판정 | AU6이 AU12와 함께 나타나는지 (자발적 미소의 특징) |
| 정서가·각성도 | AU 조합으로 로컬 계산한 valence / arousal |
| 계측 안정성 | 여러 프레임에 걸친 AU 분산 |

OpenRouter는 이 수치를 근거로 **표정 이름 · 한 줄 요약 · 감정 추정 4종 · AU별 판단 근거 ·
기하 지표 신호 · 자발성 판단 · 신뢰도 · 주의사항**을 JSON으로 돌려줍니다.

시스템 프롬프트에서 신원·나이·성별·인종·건강·거짓말 판정은 금지하고, 표정은 겉으로 드러난
신호일 뿐 속마음의 증거가 아니라는 점을 단정하지 않도록 지시합니다.

## 실행

1. `.env`에 OpenRouter 키를 넣습니다. 필요한 키는 이것 하나뿐입니다.

```env
OPENROUTER_API_KEY=여기에_OpenRouter_API_키
```

2. 의존성 설치 후 개발 서버를 띄웁니다.

```bash
npm install
npm run dev
```

3. `http://127.0.0.1:5174`를 열고 카메라 권한을 허용합니다.

카메라를 쓰지 않으려면 `사진 올리기`로 JPG, PNG, WebP 사진을 고르세요 (최대 12MB).

프로덕션은 `npm run build` 후 `npm start`로 `http://127.0.0.1:8788`에서 서빙합니다.

개발 중 판독서 레이아웃만 확인하고 싶다면 `http://127.0.0.1:5174/?demo=1`로 열면
API 호출 없이 예시 판독서가 뜹니다 (개발 빌드 전용).

## 호출이 나가는 경로

1. **모든 계측은 브라우저에서** — 랜드마크 추출, AU 계산, 기하 지표, 머리 각도, 실시간 막대
   그래프까지 전부 로컬입니다. API 비용 0.
2. **버튼을 눌러야만 호출** — 실시간 스트리밍 분석은 하지 않습니다. 3초 계측 후 한 번만 보냅니다.
3. **한 번의 요청** — AU 수치 JSON과 640px JPEG를 함께 보내 판독을 받습니다.
   쿨다운·rate limit·일일 한도·캐시는 두지 않습니다.

요청당 토큰은 `reasoning: { enabled: false }`, `max_tokens: 420`, JSON 모드,
활성화된 AU만 최대 8개 전송으로 적당히 유지합니다.

모델은 `.env`에서 바꿀 수 있습니다.

```env
OPENROUTER_VISION_MODEL=qwen/qwen3.6-27b
```

## 구조

```
server.js        Express API. OpenRouter 호출, 입력 검증, 보안 헤더
src/face.js      AU · 기하 지표 계측 (브라우저 전용, 네트워크 접근 없음)
src/App.jsx      카메라/사진 상태 머신, 실시간 계측 UI, 판독서
src/styles.css   계측 장비를 닮은 밝은 디자인
```

## 보안

`security-best-practices` 스킬의 Express / React 가이드를 적용해 만들었습니다.
적용 내역과 자체 점검 결과는 [`security_best_practices_report.md`](./security_best_practices_report.md)에 있습니다.

요약하면 API 키는 서버 `.env`에서만 읽고 프런트엔드 번들에 들어가지 않으며,
요청 본문은 타입·구조·크기를 모두 검사하고, 서버는 127.0.0.1에만 바인딩합니다.

## 알아두실 점

- 카메라는 `localhost` 또는 HTTPS에서만 동작합니다.
- 표정 판독은 겉으로 드러난 근육 신호에 대한 해석입니다. 속마음, 진위, 건강 상태의 증거가 아닙니다.
- 하루 호출 상한과 rate limit은 단일 프로세스 메모리에 저장됩니다. 여러 인스턴스로 배포한다면
  Redis 같은 공유 저장소로 옮겨야 합니다.
